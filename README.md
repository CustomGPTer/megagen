# MegaGen

MegaGen is a free Android player for the Sega game files you own: Mega Drive, Mega CD, 32X, Master System, Game Gear, SG-1000 and Pico. A six-button pad you design, save states with pictures, run-ahead, CRT and composite looks, light gun and mouse by touch, and two-phone play over Wi-Fi. No games included, no adverts, no account.

Website: https://customgpter.github.io/megagen/

Download: https://github.com/CustomGPTer/megagen/releases/latest/download/MegaGen.apk

## Engine source

MegaGen runs Genesis Plus GX and PicoDrive, unchanged, as separate libraries. Their source, exactly as built for MegaGen, is in [engine/](engine/) with the commits and build steps, so either can be rebuilt and replaced. The rest of the app's source is not published.
